Context tools · Preview

Sift

Keeps the current task intact while finding relevant context in long coding-agent histories, without first asking a model to summarize the history.

59.66% fewer provider-reported prompt tokens than full context in one public, previously exposed 344-question LongBench v2 cohort; task-majority accuracy was 5.25 percentage points below full context.
