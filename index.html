Spot Advisor

When a coding agent reaches a decision that could change its next move, Spot prepares one concise, evidence-backed question for a frontier model and returns a next step with a local check.

Context tools · Preview

Sift

Preserves the active task and selects relevant evidence from long coding-agent histories without asking a model to summarize them.

59.66% fewer prompt tokens in one 344-question LongBench v2 cohort; task-majority score was 5.25 points lower than full context.
